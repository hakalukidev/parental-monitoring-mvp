# Implemented secondary features and remaining limits

Supported public call/SMS history, audio-only check-ins and selected notification metadata are implemented. The [current completion report](ENGINEERING_REPORT_1_3.md) records real coverage, consent behavior, tests and deployment; the [1.2 report](ENGINEERING_REPORT_1_2.md) records selected-media infrastructure and model evaluation requirements.

Remaining work is a licensed evaluated on-device photo/video model, broader physical/OEM/browser/provider acceptance, actual MMS/attachment feasibility, real TURN relay acceptance, iOS builds and complete account/export UX. Private encrypted messaging/VoIP stores and telephone audio are outside the implemented scope. Payments/subscriptions were excluded from this task.
